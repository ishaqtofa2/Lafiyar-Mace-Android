Lafiyar Mace Tools restoration

Based on the supplied lafiyar_mace_ads_banner_fallback(2).zip. Only ToolsActivity.java was replaced, using the result-card + Rewarded Ad image-download implementation and adding a visible bilingual Tools Manual button. The manual explains Period, Pregnancy, Ovulation, Symptoms, and Ask a Doctor in English and Hausa.

Download behavior: result card is saved as PNG only after the Rewarded Ad reward callback fires. If no rewarded ad loads, download does not proceed.

Build and test in Android Studio before installing; this ZIP was not built against your live backend/device in this environment.
